# Código de conduta

O PrimePC é um projeto aberto a qualquer pessoa, de qualquer nível de experiência. Para que continue assim:

- Seja respeitoso e paciente, principalmente com quem está começando.
- Critique o código e as ideias, nunca a pessoa.
- Sem ofensas, assédio, discriminação, ameaças ou exposição de dados pessoais de alguém.
- Discuta divergências técnicas com argumentos e testes, não com insistência.

Quem mantém o projeto pode editar ou apagar comentários, issues e pull requests que violem estas regras e bloquear quem
insistir no comportamento. Para relatar um problema de conduta, use o relato privado descrito em [SECURITY.md](SECURITY.md).
